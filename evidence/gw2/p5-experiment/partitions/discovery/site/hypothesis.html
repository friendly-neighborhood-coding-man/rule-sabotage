Submit a hypothesis

A hypothesis is a rule you think the game follows, stated in your own words. One form per hypothesis. You do not have to give a hypothesis for every aspect of the game, and you may submit competing hypotheses for the same behaviour. If you cannot decide, abstain instead: abstaining is a valid answer. Everything you submit is stored exactly as written and is never overwritten; submit a new form to revise.

Optional structured representation

You may add a machine-readable version of a hypothesis. It is optional: free text alone is a complete submission. What you type is stored exactly as written; it is never corrected or completed. If it cannot be read, that is recorded and only your free text remains.

Format: {"schema": "gamewatch/gw2-hypothesis@1", "clauses": [ … ]}. A clause is either

  • a law: {"form": "law", "situation": KIND, "when": EXPR (optional), "expect": [{"field": OUTCOME, "equals": EXPR}, …]}: in every situation of that kind where when holds, each outcome field equals the expression (computed from input fields only);
  • an invariance: {"form": "invariance", "situation": KIND, "when": EXPR (optional), "groupBy": [INPUT, …], "vary": [INPUT, …], "outcomes": [OUTCOME, …]}: situations that agree on groupBy have the same outcomes whatever the values of vary.

Expressions: {"op": "const", "value": V}, {"op": "field", "name": INPUT}, and {"op": O, "args": [EXPR, …]} with O one of eq, ne, lt, le, gt, ge, and, or, not, in, add, sub (in takes one argument and "values": [V, …]). A field that a record does not establish is unknown; a situation with an unknown input or outcome is not counted for or against a clause.

Situation kinds and fields

turn-start

Input fields: build (string), side (string), turn (number), isFirstMover (boolean), piecesOnBoard (number), pendingBonus (number)

Outcome fields: actionsGranted (number)

effect-entry

Input fields: build (string), effect (string), effectKind (string), pieceSide (string), effectOwner (string), ownerRelation (string), arrival (string), chainDepth (number), capped (boolean), pieceShieldedBefore (boolean), multiCell (boolean)

Outcome fields: fired (boolean), absorbed (boolean), cellUsedUp (boolean), shieldAfter (boolean), otherCellsRemain (boolean), sentHome (boolean)

effect-placement

Input fields: build (string), side (string), effect (string), effectKind (string), cellCount (number), nearAnyPiece (boolean), cellOccupied (boolean)

Outcome fields: placed (boolean)
