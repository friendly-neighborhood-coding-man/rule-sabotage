# Skill: Analyzer

Produce actionable, honest QA results.

- Bug discovery: Kane reviews the pages blind (objective mode) and files findings through the form. One call, only with
  operator authorization. Kane's words are kept verbatim and labelled as Kane's.
- Balance analysis: GameWatch's own statistics from the AI games (first-mover wins, matched pairs, sign test, resource
  per seat). Labelled as engine statistics, not Kane.
- Coverage audit: which rules and evidence the review cited, and what nobody looked at.
- Closed loop: a coding agent gets only the findings and a blind workspace, reproduces each finding with a scripted
  playtest, fixes, and re-runs the same playtests.
- Regression review: compare scripted playtests against the reference build before and after the fix.
- Report: one QA report; anything not run is stated as NOT RUN.
